## Settled decisions (2026-10-08)

- **Visual direction:** Instrument. Neutral greys, one accent, 1px hairlines. No shadows, gradients, glow, or blur on content.
- **Landing:** triage-first failure inbox. Today's Overview content moves to an Insights view.
- **Theme presets:** `default` (follows system), `light`, `dark`, and `high-contrast` stay full themes. `ocean`, `sunset`, `dracula`, `cyberpunk`, `forest`, and `rose` set the accent hue only, on whichever mode is active. `ThemeConfig` keys keep their names and no existing value errors.
- **Delivery:** inside v3. No work restyles `html-generator.ts`.
- **Fonts:** Geist Sans and Geist Mono (SIL OFL 1.1), Latin subset, variable woff2, inlined as data URIs in `dist/ui/fonts.css` (69 KB). The report shell leaves out `fonts.css` when `cspSafe: true`, so the system stack applies, as today. This removes the Google Fonts request.
- **Token source:** tokens are authored once in `src/ui/styles/tokens.ts` and emitted as CSS by the UI build, so vitest can check contrast without parsing CSS.
- **List semantics:** a grouped test list is an ARIA `tree`. Group headers are level-1 `treeitem`s and tests are level-2 `treeitem`s, rendered flat so the list can be virtualized. A `listbox` cannot hold group headers (axe `aria-required-children`).

## Design rules

Every v3 UI PR is reviewed against this list. Rules marked *(lint)* fail the build.

1. No cards around lists or stats. Separate with 1px hairlines and spacing. *(lint: `box-shadow` only through `--elevation-*`)*
2. Colour is signal. Neutrals for structure. Status hues only on status glyphs, counts, chart marks, and the `-bg` tints of diff lines and failing rows. One accent for focus, selection, and links. *(lint: no hex, `rgb()`, or `hsl()` outside generated `tokens.css`; no gradients, `backdrop-filter`, or `text-shadow`)*
3. Two radii: 4px for controls, 6px for floating layers. *(lint: `border-radius` is a token, `0`, or `50%`)*
4. Type: 13px base. Scale 11 / 12 / 13 / 15 / 20 / 28. Weights 400 / 500 / 600. Section titles are sentence case at 13px/600, with no icon and no letter-spacing. Mono only for code, paths, durations, and IDs. Every number uses `tabular-nums`.
5. Density: list rows 32px, compact 28px. No padding above 24px inside a view.
6. Status is never colour alone. Each status has a fixed SVG glyph plus a text label: failed, passed, flaky, skipped, quarantined.
7. A list row shows the status glyph, title path, `file:line`, retry count, duration, and at most one signal marker. Marker priority: new failure, regression, flaky, quarantined, slow. Grade letters move to the detail pane.
8. Motion: opacity and transform only, 150ms or less, none under `prefers-reduced-motion`.
9. Every action is reachable by keyboard. Every view, filter set, and selected test has a hash URL.

## Tokens

Roles, not hex. D1 fixes the values; a test checks them.

- **Neutral:** `--bg`, `--bg-subtle`, `--bg-hover`, `--bg-selected`, `--border`, `--border-strong`, `--text`, `--text-muted`, `--text-faint`. Separate ramps for light and dark. The dark base is a hue-neutral near-black, not `#000` and not blue-tinted.
- **Status:** `--fail`, `--pass`, `--flaky`, `--skip`, each with `-fg` and a subtle `-bg`. `slow` and `regression` get no hue; they use a neutral marker and an icon.
- **Accent:** `--accent`, `--accent-fg`, `--focus-ring`. Default hue is blue (about 220°). Accent presets replace the hue only.
- **Scale:** space 4 / 8 / 12 / 16 / 24 / 32. Radius 4 / 6. One elevation token for floating layers. Motion 100ms and 150ms with one easing curve.
- **Contrast floor (tested in `tokens.test.ts`):** text tokens at least 4.5:1 on all four surfaces. Status `-fg` at least 4.5:1 on `--bg`, `--bg-subtle`, and its own `-bg` tint, because counts are text, and at least 3:1 on hover and selected rows. Accent at least 4.5:1 as link text, and `--accent-fg` at least 4.5:1 on the accent fill. `--border-strong` at least 3:1 for control edges. High-contrast text and accent at least 7:1.
- **`ThemeConfig` mapping:** `background` → `--bg`, `surface` → `--bg-subtle`, `text` → `--text`, `primary` and `accent` → `--accent`, `success` → `--pass`, `error` → `--fail`, `warning` → `--flaky`. Custom colours apply as given; the contrast test covers built-in themes only.

## Layout and information architecture

```
┌ top bar 40px ─ branch · commit · CI link · time │ ✕13 ✓37 ◐4 –2 │ gate │ 1m 42s │ ⌘K │ theme │ export ┐
├ rail 200px (⌘B) ─┬ list pane (virtualized) ────────┬ detail pane (resizable) ──────────────────────┤
│ Failures      13 │ filter bar: status:failed tag:… │ title · file:line · project · status · retries │
│ Flaky          4 │ ▾ toBeVisible timeout (11)      │ error · expected/received · code frame         │
│ Regressions    2 │   ✕ checkout › pays …     2.1s  │ AI analysis · copy prompt                      │
│ Quarantined    1 │ ▾ toHaveText mismatch (2)       │ steps, failing step expanded                   │
│ All tests     56 │   ✕ login › rejects …     0.8s  │ attachments · trace                            │
│ ──────────────── │                                 │ network · console                              │
│ Insights         │                                 │ history sparkline · flake stats                │
│ History          │                                 │ annotations                                    │
│ Gallery          │                                 │                                                │
│ Live             │                                 │                                                │
└──────────────────┴─────────────────────────────────┴────────────────────────────────────────────────┘
```

- **Queues** (Failures, Flaky, Regressions, Quarantined, All tests) are saved filters over one list. Failures groups by failure cluster by default. The other queues group by file.
- **Filters** leave the sidebar and become a token filter bar above the list. The bar and the ⌘K palette use one token syntax and one parser.
- **Detail order** follows triage: what failed, why, evidence, history. Sections collapse. Collapse state persists in `localStorage`, wrapped in try/catch.
- **Insights** holds every current Overview panel: health grade, gates, quarantine, cluster summary, regressions, fixed, new, slowest, most flaky. It uses one stats row with sparklines and plain lists, not tiles.
- **History** merges Trends and Comparison as two tabs.
- **Green run:** the top bar reads "No failures" next to the passed, flaky, and skipped counts. The landing opens the Flaky queue, or All tests when Flaky is empty. The landing is never an empty inbox. ("All N passed" was dropped: it is false when tests are flaky or skipped.)
- **Below 900px:** the rail becomes a menu, and the detail pane opens as its own route over the list.
- **Theme control:** two parts. Mode is System, Light, Dark, or High contrast. Accent is Default, Ocean, Sunset, Dracula, Cyberpunk, Forest, or Rose.
- **Live:** rail entry stays. Its content is ported by roadmap Phase 2.

## Interaction

- **Keep:** ⌘K, ⌘B, j/k and arrows, Enter, Esc. Also keep (Appendix A resolutions): `f` (next failure), `n` (next flaky), `e` (export summary), and `1`–`5`, remapped to Failures, All tests, Insights, History, Gallery.
- **Add:** `/` focuses the filter bar. `[` and `]` move to the previous or next failure from the detail pane. `g f`, `g l`, `g i`, `g h` go to Failures, Flaky, Insights, History. `c` copies the failure summary. `?` opens the keymap overlay.
- **Routes (hash):** `#/q/failures`, `#/q/flaky`, `#/q/regressions`, `#/q/quarantined`, `#/q/all`, `#/test/<id>`, `#/insights`, `#/history/trends`, `#/history/compare`, `#/gallery`, `#/live`. The filter set follows the route as a query string.
- **Focus:** a visible 2px `--focus-ring` on every interactive element. List selection and keyboard focus are the same state.
